联调修正
此前 MCP isError 返回被作为未处理异常抛出，单个页面超时可能中断整项任务。
现改为 LangChain ToolException + handle_tool_error，让模型收到 status=error 的工具消息，并可继续处理；工具错误仍显示在执行过程。
嵌套 TaskGroup 异常会提取具体原因，保留可读的模型繁忙提示。
真实 MCP Fixture 回归测试验证：同一连接先访问失败，再读取成功，连接与后续流程未中断。
全部后端 64 项测试通过。
