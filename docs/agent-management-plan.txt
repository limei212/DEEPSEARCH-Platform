Agent 管理实施方案（2026-10-12）

目标：实现已确认的 Agent 详情页、资源中心和主 Agent 自动调度。
技术：现有 FastAPI、Python 3.12、React、Ant Design；SQLite 持久化配置。
新增依赖：官方 MCP Python SDK、JSON Schema 校验。密钥使用本地加密文件保存，排除源码包。

任务 1：配置与版本管理
新增 app/management/models.py、store.py；测试 tests/test_management.py。
定义 Agent 的基本信息、提示词、输入输出、资源绑定、草稿及启用版本。
定义 RAGFlow、Skill、MCP 三种资源。以事务保存配置和版本，乐观锁阻止覆盖。
先测试草稿隔离、版本恢复、密钥掩码、缺失资源校验、配置快照。

任务 2：资源连接与运行
新增 connectors.py、runtime.py、api.py；修改 app/api/server.py 和 app/agent/main_agent.py。
RAGFlow 查询助手及关联知识库；Skill 导入 Markdown/ZIP，检查目录穿越和元数据；
MCP 使用官方 SDK 支持 HTTP、SSE、stdio，发现工具并按勾选列表连接。
草稿测试直接执行选定助手；JSON 输出、输入字段及必需内容均校验；
主任务在启动时捕获启用版本与资源快照，保持现有会话记忆和任务事件。
资源缺失、连接错误和模型未配置返回明确原因，不伪造成功。

任务 3：前端页面
新增 frontend/src/management/ 下的类型、API、AgentEditor、ResourceCenter、ResourceForm。
修改 App.tsx：动态助手列表、添加模板/空白/复制、管理资源入口、任务导航保留。
详情页六个页签，完整提示词编辑及生效预览、输入输出表格和 JSON Schema、
知识库/Skill/MCP 勾选连接、版本恢复、保存草稿、保存并启用、测试抽屉。
资源中心支持新增、编辑、测试/刷新连接、技能文件导入和查看内容。
未保存内容切页提醒；窄屏也能进入管理页面。

任务 4：验收与交付
Python unittest：真实数据库事务、协议边界替身、结构校验、运行配置隔离。
前端原有测试、tsc、Vite build；浏览器验证添加、修改、保存刷新、绑定、导航和错误提示。
重启本地后端，保存页面截图，更新 ZIP 及运行说明，不加入密钥或配置数据库。

实施记录：用户已明确要求按已确认方案直接修改；在现有运行目录增量实现，保留此前全部 UI 改动。
