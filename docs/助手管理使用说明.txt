DeepSearch Agent 管理

入口：左侧 AGENTS 标题旁的「＋」可以创建空白助手或复制现有助手。
窄屏时，先点击右上角菜单图标展开任务导航。
点击助手名称进入详情页，点击「管理连接资源」进入资源中心。

配置流程：
1. 填写名称、能力描述、系统提示词；能力描述供主 Agent 自动选择助手。
2. 在输入输出中设置字段来源、必填项、输出格式和交付文件。
3. 选择内置工具，允许检索当前会话附件，以及可使用的 Skills、MCP 工具。
4. 保存草稿，使用生效预览查看组装后的提示词。
5. 测试助手；测试会调用已配置的真实模型及工具。
6. 保存并启用。新任务使用启用版本，运行中的任务继续使用启动时的配置快照。
7. 历史版本可恢复到草稿，停用助手后，后续任务不再调度它。

资源：
- 文档检索：在助手详情的「文档检索」页勾选当前附件检索。无需服务地址、额外 API Key 或 Docker。
  支持 PDF 文本页、DOCX 段落/表格、TXT、Markdown。先在对话或助手测试页上传附件，再发送问题。
  每轮任务临时建索引，结束/失败/取消后释放；上传原文件保留供再次查询。
  首次使用下载 FastEmbed 中文模型，缓存的是模型权重，文档向量不持久化。扫描 PDF 需要先 OCR。
- Skills：可以编辑 SKILL.md，或导入单个 Markdown / ZIP 技能包。
  技能需要 YAML 头部中的 name 和 description，可写 version、required_tools。
  首版支持 UTF-8 文本资料，展开后最多 5MB / 100 个文件。脚本作为文本读取，不自动执行。
- MCP：支持远程 HTTP、SSE，以及本地 stdio。测试连接发现工具，助手只能使用已勾选工具。
  本地命令在 Python 后端所在电脑执行，所需程序应已安装并在该环境可用。

保存位置：
项目根目录 .agent-data/config.sqlite3 保存配置和版本；secrets.key 用于加密资源密钥。
配置会在重启、刷新后保留。该目录不进入 Git 或可下载源码 ZIP。
需要迁移已保存配置时，必须同时迁移数据库和 secrets.key；仅复制数据库无法解密认证信息。
模型密钥仍使用项目根目录 .env。修改模型配置后，需要重启后端。

验证命令（项目根目录）：
.venv\Scripts\python.exe -m unittest discover -s tests -v
前端目录：npm.cmd test；node node_modules\typescript\bin\tsc -b

本次验证覆盖配置版本隔离、JSON Schema、密钥保护、文件边界，以及文档任务索引生命周期、本地 MCP stdio/HTTP 协议和历史兼容接口。
远程 MCP、数据库与模型联合运行，需要填写可用服务和密钥后在测试面板确认。默认文档助手已替换原 RAGFlow 助手。

联网搜索已切换为 Exa：在根目录 .env 配置 EXA_API_KEY，重启后端。
默认返回 5 条结果及摘录；请求正文时每页最多 12000 字符。
news 对应 Exa 新闻分类；finance/general 使用原问题通用检索，不限定为财报。
