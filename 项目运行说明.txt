DEEPSEARCH Platform

本项目基于 https://github.com/didilili/deepsearch-agents，包含浅色界面、任务列表、Agent 管理和资源中心。
原始提交：d0f6eed1e14b1b457942ba2a0195f65731aaf444。

环境：Python 3.12，Node.js 24，pnpm 10.33.0。

一、安装后端依赖
在项目根目录打开 PowerShell：
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-locked.txt
或者：uv sync --frozen

二、复制环境模板
Copy-Item .env.example .env
根据需要填写模型、Exa、中文文档检索模型和可选 MySQL 配置。
没有实际模型密钥可以先查看界面；真实研搜和助手测试需要可用模型。

三、启动后端并保持窗口打开
$env:PYTHONUTF8='1'
.\.venv\Scripts\python.exe -m uvicorn app.api.server:app --host 127.0.0.1 --port 8000

四、另开终端，在 frontend 目录安装并启动
npm.cmd install -g pnpm@10.33.0
pnpm.cmd install --frozen-lockfile
Copy-Item .env.example .env.local
pnpm.cmd dev:compat

打开网页：http://127.0.0.1:5173/
接口文档：http://127.0.0.1:8000/docs
前端构建：pnpm.cmd build:compat

兼容启动使用 npm 官方 esbuild-wasm 包，无需外部运行目录；原生 esbuild 正常的环境也可使用 pnpm dev / pnpm build。
macOS/Linux 中将 .venv\Scripts\python.exe 换为 .venv/bin/python，将 Copy-Item 换成 cp；Node 命令去掉 .cmd。

助手管理：参考 docs/助手管理使用说明.txt。
测试：项目根目录执行 .venv\Scripts\python.exe -m unittest discover -s tests -v；前端目录执行 pnpm test。

配置保存在 .agent-data，认证密钥加密保存。该目录、.env、上传与输出文件、依赖目录、运行日志不进入 Git。
任务历史保存在 .agent-data/tasks.sqlite3，包括问题、全部执行事件、最终答案与输出文件入口。
刷新网页会恢复选中的历史任务；任务列表按每页 50 条向下加载，不设总条数上限。
网页刷新不会取消后台任务；后端重启会保留历史并将未完成任务标记为中断，需要重新提交。
备份时保留 .agent-data 和 app/output；完整恢复上传附件还需保留 app/updated。
此次功能启用前未保存的网页内存记录无法恢复，已有输出文件仍保留在 app/output。
本项目通过本地 127.0.0.1 运行，上传 GitHub 后不会自动变成公网网站。

文档检索助手已内置：上传 PDF/DOCX/TXT/MD 后提问，不需要 Docker 或知识库服务。
附件保留在 app/updated，刷新后可见；每轮任务索引只在内存中存在，终态释放。
.model-cache/fastembed 仅缓存首次下载的模型权重，不保存文档索引；不要提交到 Git。
